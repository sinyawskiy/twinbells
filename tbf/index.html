Открытый формат

TwinBells Format

TBF — открытый JSON-формат для переноса упражнений, метрик, программ и истории тренировок между приложениями. Формат не зависит от Android, Room или внутренней модели базы TwinBells.

TBF 1.0 JSON Schema SHA-256 checksums CC0

Зачем нужен TBF

TwinBells хранит данные локально и не требует аккаунта. TBF позволяет выгрузить один объект вместе с его зависимостями и передать его другому человеку, тренеру или в другое приложение.

  • Метрика — определение показателя: вес, повторения, время, дистанция.
  • Упражнение — карточка упражнения и его метрики.
  • Программа — программа тренировок, упражнения, метрики и суперсеты.
  • Журнал — история тренировок и замеры тела.

Сценарий «тренер и клиент»

Обмен работает без облака, аккаунта и сервера. Файлы передаются любым удобным способом: в мессенджере, по почте, через файлообменник или USB.

  1. Тренер экспортирует программу: «Программы» → ⋮ → «Экспорт в TBF».
  2. Клиент импортирует файл через настройки или открывает ссылку «Открыть в TwinBells». Программа попадает в общую библиотеку приложения.
  3. Клиент тренируется по программе и экспортирует журнал: «Дневники» → ⋮ → «Экспорт в TBF».
  4. Тренер импортирует журнал. Он создаётся отдельным дневником, существующие данные не меняются.

Программы общие для всех дневников. История тренировок, подходы и замеры тела принадлежат конкретному дневнику. Журнал не содержит программ: если тренеру нужна программа клиента, её можно создать из любой завершённой тренировки в импортированном журнале.

Приватность: журнал содержит имя, заметки, историю тренировок и замеры тела. Отправляйте его только тому, кому доверяете. Повторный импорт того же файла не создаёт копий.

Как читать TBF

Каждый файл — один документ с корневым объектом и всеми зависимостями. Импортер проверяет версию, схему, ссылки и checksum каждого объекта, строит план импорта и применяет его одной транзакцией.

Checksum считается по смысловому содержимому объекта. Одинаковые объекты не дублируются: если checksum уже есть в базе, объект используется повторно; если отличается — добавляется новый.

Важно: TwinBells не требуется для чтения TBF. Любое приложение может реализовать импорт по спецификации и JSON Schema.
